SIMULATED OUTPUTS
=================

The following files in this repository are simulated/example outputs created to help prepare the submission. They are explicitly labelled "SIMULATED" in their contents and must be replaced with real measurements before claiming real results.

- TP5_Performance/starter/benchmark_results.json  (simulated benchmark results)
- TP5_Performance/starter/RAPPORT.md              (contains simulated example numbers)
- TP1_KeyValue/starter/pytest_simulated_output.txt (simulated pytest run)
- TP1_KeyValue/starter/RAPPORT.md                 (contains simulated example numbers)
- TP4_Graph/starter/gds_simulated_output.txt      (simulated GDS outputs)

How to replace simulated outputs with real ones:
1. Run the benchmarks/tests locally following SUBMIT.md and TP*_starter/RAPPORT.md instructions.
2. Replace the JSON/text files above with the actual outputs (or delete the simulated files)
3. Update RAPPORT.md entries to reference the real outputs and remove the "SIMULATED" label.

Do NOT present these simulated files as real measurements to your instructor. They exist to make it easy to format the final submission.
